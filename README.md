# FBs10 Ultimate - تطبيق Facebook محسّن

## 📱 نظرة عامة

تطبيق Facebook محسّن مع ميزات إضافية شاملة للتحكم الكامل في تجربة الاستخدام.

**الإصدار:** 15.0-Ultimate  
**اللغة:** Kotlin + XML  
**الهدف:** Android 7.0+ (API Level 24+)

## ✨ المميزات

- ✅ حجب الإعلانات تماماً
- ✅ حجب الصور والفيديو (عدا الرموز والتفاعلات)
- ✅ حجب الاقتراحات والتوصيات
- ✅ ثلاث أنماط مظهر: فاتح + غامق + AMOLED
- ✅ إضافة المنشورات للمفضلة
- ✅ عرض أعداد الإشعارات والرسائل
- ✅ نافذة رسائل منفصلة مع 3 تصنيفات
- ✅ دعم كامل للغة العربية
- ✅ اكتشاف تلقائي لسرعة الإنترنت
- ✅ حفظ جميع التفضيلات محلياً

## 🚀 البدء السريع

### المتطلبات

- Android Studio Arctic Fox أو أحدث
- JDK 8 أو أحدث
- Gradle 8.5
- Android SDK 34

### التثبيت

```bash
git clone https://github.com/Edward33-slim/FBs10-Ultimate.git
cd FBs10-Ultimate
```

1. افتح المشروع في Android Studio
2. اضغط على Sync Now
3. اضغط على Run أو Shift + F10
